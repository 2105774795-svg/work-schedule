# Work Schedule · 工作计划编制

为咨询项目编制开项工作计划。按三级任务树选择工作和交付成果，为任务安排月份和多名项目成员，在网页内调整人天与分工，并导出可编辑的 Excel。

## 本地运行

建议使用 Node.js 24 或更高版本。运行时无需安装 npm 依赖。

```sh
node server/plan-server.cjs
```

打开 [http://127.0.0.1:8877](http://127.0.0.1:8877/)。首页可以离线载入虚构的产业园咨询示例，体验任务、月历与 Excel 导出。新项目的自动任务生成需要配置 AI。计划和人员库默认保存在当前浏览器，可通过页面备份和导入。

## 可选 AI 配置

复制 `server/.env.example` 为 `server/.env`，填写 `PLAN_AI_BASE_URL`、`PLAN_AI_API_KEY` 和 `PLAN_AI_MODEL`，然后重新启动本地服务。基地址应为模型服务提供的 API 前缀（例如 `https://api.moonshot.cn/v1`）。

- 任务树生成根据项目范围和规模拟定任务，并在应用前校验任务结构和数量。
- 增补任务的联网推荐需要支持网页检索的接口。Moonshot 官方接口可以复用模型配置，也可以配置独立的 `PLAN_SEARCH_BASE_URL` 和 `PLAN_SEARCH_API_KEY`。
- 人天初算提供工作量依据及分工建议，由程序校验月份、人员和人天合计。应用初算时保留人工已确认的数据。

使用 AI 时，相关项目内容会发送给你配置的服务商。请使用有权处理的数据，并把真实密钥保存在本地配置中。

## Excel 导出

主表为计划月历，可选导出月度人力汇总、月度任务明细、人员月度负荷、说明及人员。工作簿按当前计划生成，修改后的 Excel 独立于浏览器中的草稿。
